## 1. 总体数据流图

一句话主干：**上行音频 → 接收循环 → 引擎出话轮 → pipeline_worker → 快脑生成 → 统一语音出口 → TTS → 回给用户**；三条支路挂在主干上（委派、交付、回退）。

```mermaid
flowchart LR
    U["用户·浏览器<br/>WebRTC AEC/NS/AGC · 16kHz 160ms chunk"]

    subgraph APP["Web app :8090"]
        direction LR
        RL["接收循环<br/>重采样→引擎分发→barge-in 迟滞"]
        PW["pipeline_worker<br/>ASR→门控→历史→生成→TTS"]
        SP["_run_speech_pipeline 统一语音出口<br/>complete 触发宽限保持窗"]
        AR["AgentRuntime<br/>任务表/议程/空档期交付仲裁"]
    end

    subgraph TURN["轮次层（会话级热切换 turn_engine）"]
        direction TB
        SE["soulx 引擎（默认）<br/>turn server :8000 · GPU5"]
        FE["frc 引擎（FrcEngine）"]
    end

    subgraph FRCSVC["frc 依赖服务"]
        direction TB
        PV["pvad :8086 CPU"]
        UV["ultraVAD :8082 · GPU5"]
        ASR["FireRedASR :8010 · GPU5<br/>整句转写 PUNC+ITN"]
    end

    subgraph BRAIN["模型层"]

        SB["慢脑 :6008 · GPU1<br/>agent 循环 · 工具调用"]
    end

    NET["外部网络<br/>web_search / fetch_page"]
    VT["VoxCPM2 :8085 · GPU7（默认）"]
    FT["FireRedTTS :8081 · GPU7（回退）"]

    U -->|"WS 上行 16kHz·160ms"| RL
    RL -->|"160ms chunks"| SE
    RL -->|"会话级二选一"| FE
    FE --> PV & UV & ASR
    SE -->|"话轮文本 + trigger"| PW
    ASR -->|"整句转写"| PW
    PW -->|"LLM 文本分段"| SP
    PW -->|"生成 /chat"| FB
    SP -->|"文本流式→合成"| VT
    VT -->|"24kHz PCM audio_chunk"| U
    AR -->|"空档期交付（同一出口）"| SP

    AR -->|"后台任务"| SB

    SP -.->|"回退"| FT
```

实线为音频/文本主数据流，双向线为控制流（委派/取消），虚线为回退路径与外部依赖。

## 2. soulx 引擎话轮生命周期（时序）

```mermaid
sequenceDiagram
    autonumber
    participant U as 用户
    participant W as Web app :8090
    participant T as turn server :8000
    participant L as 快脑 :6007
    participant S as VoxCPM2 :8085

    U->>W: 音频 chunk（160ms）
    W->>T: vad.process(chunk)
    alt wait 路径（静音确认，turn_wait_ms 可调）
        T-->>W: speak{segment, trigger=wait}
        W->>L: 生成（无宽限，立即接话）
    else complete 路径（预测即触发）
        T-->>W: speak{segment, trigger=complete}
        W->>W: 宽限保持窗（turn_grace_ms 可调，默认 0.9s；生成进 held_chunks）
        alt 窗口内持续复语
            W->>W: 静默丢弃整次生成（不进历史）
            Note over W: 续说经 groupby 并成完整句
        else 窗口平安过期
            W->>U: turn_start
            W->>S: _flush_held() 逐段合成
        end
    end
    L-->>W: 分段文本（S/R/T 流）
    W->>U: text_response + audio_chunk
    Note over U,W: 播放期复语：3 块迟滞 → interrupt<br/>（每 episode 单次打断）
```

## 3. frc 引擎决策流（双 EOT）

```mermaid
flowchart TB
    A["chunk feed"] --> B{"onset?<br/>3 块连续 prob≥0.5"}
    B -- 否 --> Z["丢弃（<3 块判噪声毛刺）"]
    B -- 是 --> C["speech（携带 2.5s 前滚）"]
    C --> D{"连续 0.4s prob<0.5?"}
    D -- 否 --> C
    D -- 是 --> E["EOS · decision_gen 自增"]
    E --> F["双通道并行（代际校验）"]
    F --> G["ultraVAD :8082<br/>20s 窗 + 助手文本"]
    F --> H["FireRedASR :8010 转写<br/>→ :6007 /v1/score 是/否概率"]
    G --> I{"min(uv, llm) ≥ 0.2?"}
    H --> I
    I -- 是 --> J["快速提交"]
    I -- 否 --> K["hold 至 EOS+6.0s"]
    K --> L{"窗口内复语?"}
    L -- 是 --> M["取消待提交<br/>话轮继续生长"]
    L -- 否 --> J
    J --> N["整句转写 → pipeline_worker<br/>（与 soulx 同构，不叠加宽限）"]
    M --> C
```

## 4. 快慢脑 Agent 协作（时序）

```mermaid
sequenceDiagram
    autonumber
    participant U as 用户
    participant FB as 快脑 :6007
    participant RT as AgentRuntime
    participant SB as 慢脑 :6008

    U->>FB: "帮我查一下明天的天气"
    FB->>RT: delegate_task(goal)
    FB-->>U: 受理话术（同轮已委派）
    RT->>SB: 后台任务（agent 循环）
    Note over SB: web_search → fetch_page → 组织答案

    U->>FB: 闲聊其他话题
    Note over RT: 提及注入门控：未提及任务<br/>不注入 task_view → 闲聊不汇报
    FB-->>U: 正常陪聊

    alt 用户改口
        U->>FB: "算了不用查了"
        RT->>RT: auto_cancel 正则先行取消
        RT-->>FB: 注入确认提示
        FB-->>U: 确认已取消
    else 任务完成
        loop 空档期轮询
            RT->>RT: 用户空闲 + 无播放 + 无生成?
        end
        RT-->>U: 经统一语音出口交付结果<br/>（user 角色系统提示注入历史）
    end
```
