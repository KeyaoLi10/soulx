## 1. 问题②：小数点切分（确定性 bug，已修复）

### 1.1 取证

- web.log 的 LLM Chunk：`风速是 5.` | `6 米每秒。` ——两段独立合成；
- TTS 服务端 TextNormalizer 只做整串归一化：`风速是 5.` → `风速是五.`（尾点保留，"五"被拖长），`6 米每秒` → `六米每秒`；
- mic 侧 ASR 回听为「五又一米每秒」——割裂感的直接证据。

### 1.2 根因

`repo/dialogue_system/clients/llm_client.py` 的流式分段正则
`PUNCT = r"[.!?;:。！？；：\n]"` 把 ASCII `.` 一律当句边界，"5.6" 在小数点处被切成两段，各自独立进 TTS。整串归一化本是完美的（`风速是 5.6 米每秒` → `风速是五点六米每秒`），是分段把它毁了。

### 1.3 修复（repo 仓 `45f888a`）

```python
# ASCII . 和 , 夹在数字之间不切分
PUNCT = r"(?<!\d)\.(?!\d)|[!?;:。！？；：\n]"
MORE_PUNCT = r"(?<!\d)\.(?!\d)|(?<!\d),(?!\d)|[、，。！？；：\n!?;:]"
```

lookaround 保证其它场合的句点/逗号行为完全不变；小数点悬在 buffer 尾部（"风速是 5."）时不再触发切分，等后续文本到齐或流结束兜底（`generate_with_history` 末尾整段 yield）一起出。

### 1.4 验证

- offline `pop_segment` 单测：`风速是 5.6 米每秒。今天风不大。` → 单段；`圆周率约等于 3.14159，明白了吗？` → 单段；短句/正常句切分行为不变；
- app 已于 16:49 重启加载新代码，活跃会话经前端自动重连无感续上；
- 线上 TTS 整串冒烟：`风速是 5.6 米每秒。` → ASR 回听「风速是五点六米每秒」，单次合成。

## 2. 问题①：数数乱音 / 音色崩（LoRA 不稳，已切回 step_0000500）

### 2.1 取证（会话 sidecar + 复现）

- run3（第一次数数）：内容级乱音，转写「一二三三五六三五哈九哈可怕，他还鸟到双溪了…」，用户当场抢话"你这说的啥呀我靠"；
- run5（重试）：内容干净但音色崩，ECAPA 对 anchor 0.574（正常段 0.68-0.73，同批注册）——即"完全不是正常的声音"；
- 复现实验（15 次调用）：灾难性乱音 ~1/15，与标点变体（、/，/空格/文字"一二三"）、timesteps 25、cfg 3/4 无关；TextNormalizer 输出干净——问题在声学模型侧。

### 2.2 A/B 定位（本报告的核心证据，GPU 6 独立进程，不动线上）

背景：11-03 曾把 LoRA 从 step_0000500 切到 step_0000400（lijunlin 的 cs_lora_refmix"最终"checkpoint），**当时没有做任何质量 A/B**；而 anchor（data/voxcpm_anchor.wav，10-29 生成）是 step_0000500 时代的产物——11-03 起线上一直是「lora400 + 失配 anchor」。

两轮 A/B（同一 anchor/自锚、cfg 2.0、timesteps 10、数数文本，Paraformer 转写 + pvad ECAPA 对各自 anchor 打分）：

| 配置 | 数数文本 ECAPA（8 reps，round 2） | 均值 / 最低 |
|---|---|---|
| **lora400 + 旧 anchor（线上现状）** | 0.584 0.640 **0.422** 0.568 0.537 **0.419** 0.455 0.521 | **0.518 / 0.419** |
| lora400 + 自锚 | 0.506-0.640 | 0.566 / 0.506 |
| lora500 + 旧 anchor | 0.531-0.693 | 0.607 / 0.531 |
| lora500 + 自锚 | 0.545-0.693 | 0.614 / 0.545 |

round 1（4 reps/配置）同方向：lora400 数数 0.410-0.620，base / lora500 均 0.58-0.67。

结论：
- **step_0000400 在枚举文本上音色一致性显著差于 step_0000500**（自锚条件仍差，说明不全是 anchor 的锅）；
- anchor 失配（500 时代的 anchor 配 400 的 LoRA）进一步拉低（0.566 → 0.518，且出现 0.42 级别的崩段）；
- 内容级灾难乱音在 44 次 A/B 合成中未再出现（低概率 ~1/15 事件，两轮 A/B 均未命中），无法归因到单一 checkpoint，但音色不稳的量化证据已足以支撑回退。
